# NLP Pipeline for Invoice Classification

This project uses Natural Language Processing (NLP) techniques
to classify invoices automatically.

## Features
- Text preprocessing
- Tokenization
- TF-IDF vectorization
- Machine Learning classification
- Invoice category prediction

## Technologies
- Python
- Scikit-learn
- Pandas
- NLTK
- Matplotlib

## Dataset
Invoices dataset containing multiple categories.

## Results
The model achieves high classification accuracy using NLP techniques.
